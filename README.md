# Serveur Apache — Hébergement Web Linux

Configuration et mise en place d'un serveur web **Apache** sur environnement Linux.

![Capture du site Apache](https://github.com/user-attachments/assets/aa3a583f-9c4a-44b2-9aa7-73ed8287f702)

## Description

Ce projet documente l'installation et la configuration d'Apache HTTP Server sur Linux pour héberger un site web localement et en réseau.

## Technologies utilisées

- **Système** : Linux (Debian/Ubuntu)
- **Serveur** : Apache HTTP Server
- **Protocoles** : TCP/IP, HTTPS
- **Sécurité** : Pare-feu UFW, certificat SSL

## Ce qui a été mis en place

- Installation d'Apache (`apt install apache2`)
- Configuration des Virtual Hosts
- Activation du protocole HTTPS
- Gestion des permissions et sécurisation du serveur

## Compétences démontrées

Administration système Linux, configuration réseau, hébergement web, sécurité serveur.
